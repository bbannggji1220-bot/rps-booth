# AI 가위바위보 ✊✌️✋

웹캠에 손을 보여주면 AI와 가위바위보를 하는 학교 부스용 게임입니다. 5판 3선승제로, 먼저 3번 이기는 쪽이 승리합니다.

**바로 하기:** https://bbannggji1220-bot.github.io/rps-booth/

- 손 인식은 [MediaPipe](https://ai.google.dev/edge/mediapipe) 모델로 브라우저 안에서만 처리합니다. 카메라 영상은 어디에도 전송·저장되지 않습니다.
- 인터넷 연결과 웹캠이 필요합니다. 크롬이나 엣지를 추천합니다.

## 조작

| 키 | 기능 |
|---|---|
| Space / Enter | 시작 · 다음 친구 도전 |
| R | 처음부터 |
| F | 전체 화면 |
| D | 인식 점검 화면 (손가락별 판정 값) |

## 내 컴퓨터에서 실행

Python이 설치된 Windows에서 `게임 실행.bat`을 더블클릭하면 `http://localhost:8765`로 열립니다.
